  • Funciona sem internet, depois de aberto uma vez com conexão.

Dicas

  • No iPhone e no iPad, use o Safari. Em versões recentes do iOS, o Chrome e o Edge também têm “Adicionar à Tela de Início” no botão Compartilhar.
  • Os treinos salvos ficam no aparelho. O app instalado e o navegador podem guardar listas separadas.
  • O app se atualiza sozinho: quando houver versão nova, aparece um aviso para recarregar.
